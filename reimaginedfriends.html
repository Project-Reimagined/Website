Shared worlds, less waiting.

ReimaginedFriends brings live co-op and asynchronous world sharing together. Pass a world between friends, or host it live from the pause menu.

When a session ends, only the changes are synced — not the entire world. It is free, flexible, and built for groups.

  • Shared modeContinue a world while its owner is offline.
  • Hosted modeJoin live co-op without a server setup.
  • Direct connectionsUPnP, NAT hole punching, and relay fallback.
  • Safe by defaultAutomatic backups help protect your world.

Requirements

Minecraft Java Edition · Fabric API on Fabric · Account sign-in

Beta software. Your feedback helps shape the release.

How it works

Shared Mode — asynchronous world sync

Play on a shared world even if the initial owner is offline. When the session ends, ReimaginedFriends calculates and sends only the world delta — the changes made — resulting in a much faster sync than uploading the entire world.

Hosted Mode — live co-op

Host your singleplayer world directly from the pause menu. Friends can join live co-op sessions through the ReimaginedFriends in-game menu without a complicated setup process.

Under the hood

  • Direct peer-to-peer connections using UPnP or NAT hole punching.
  • A global relay network provides a fallback when a direct connection fails.
  • Only one player can host a shared world at a time, preventing forks and desynchronization.

How it compares

ReimaginedFriends supports live co-op like Essential, e4mc, and Realms, but also supports asynchronous play when the host is offline. It is free, needs no 24/7 server setup, and has full API access in development. Simple Voice Chat support is currently in beta.

For modpack creators

You are 100% allowed to use ReimaginedFriends in any Modrinth modpack. A full API and custom interface are in development for the v1.0 release or earlier, allowing modpack creators to hide the built-in buttons and use a custom menu instead.

Beta notice, safety, and privacy

This is beta software and feedback is welcome. If the host crashes during a live match, Minecraft automatically makes a backup copy of the world data. ReimaginedFriends uses online services for logging in, delta storage, and connecting friends. Connections are made only after you accept the prompt in-game.
