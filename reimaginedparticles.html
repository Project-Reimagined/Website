What it does

Particle Designer on the web

Design custom particle shapes at reimaginedparticles.my.to by setting shape size, number of points, surface or edges-only rendering, and color. No login or download is required.

Import codes

Saving a design generates an eight-character code. Use it in-game and your shape appears where you stand.

/rp import HR4SJC3S

Commands

  • /rp import <code> downloads a saved design and spawns it at your location. Requires reimagined.admin.
  • /rp remove <id|hash|all> deletes an effect by short ID, long hash, or all at once. Requires reimagined.admin.
  • /rp list lists active effects with their ID, type, and point count. Requires reimagined.use.
  • /rp info <id|hash> shows an effect's ID, color, points, and location. Requires reimagined.use.
  • /rp identify shows floating effect IDs visible only to you. Requires reimagined.admin.
  • /rp fov <value|reset> adjusts the visibility angle to your actual FOV.
  • /rp reload reloads the config without restarting the server. Requires reimagined.admin.

Website workflow

Open the designer, adjust dimensions, point density, surface or edges mode, and color, then preview the points before entering the game. Press Save to get an import code and use it with the plugin. Shape data is created client-side and stored in a tiny shared database, so no account is needed and shapes can be viewed on any server using the plugin.

Visibility and safety

Particles are sent only to players looking toward them and within range. Turn away and they stop rendering, reducing network bandwidth and server load. Per-player FOV settings keep culling accurate, while configurable limits control points per effect and total active effects.

Requirements

Minecraft 26.1 or higher · Paper, Purpur, or Spigot. This is a server-side plugin: vanilla clients can connect and see the particles, with no client mod or resource pack. Active particles are stored on disk and reload after restarts.
